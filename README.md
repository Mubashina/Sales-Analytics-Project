# Sales Analytics Dashboard

## Project Overview

This project focuses on analyzing sales data to understand sales performance and profitability across different categories, regions, months, and products.

## Objective

To analyze sales data and identify patterns and trends in sales, profit, product performance, categories, and regions using Excel, MySQL, and Power BI.

## Tools Used

- Microsoft Excel – Data preparation and analysis
- MySQL Workbench – SQL queries and data analysis
- Microsoft Power BI – Interactive dashboard and data visualization

## Project Workflow

Sales Dataset → Excel → MySQL → Power BI → Insights

## Data Preparation

The sales dataset was prepared and organized before performing the analysis. The data was examined for proper formatting and consistency, and the required fields were used for further analysis in MySQL and Power BI.

## SQL Analysis

The prepared sales data was analyzed using MySQL Workbench. SQL queries were used to calculate total sales and profit and to analyze performance by category, region, month, and product.

SQL techniques used include aggregate functions, GROUP BY, HAVING, CASE, JOIN, LEFT JOIN, and subqueries.

## Power BI Dashboard

An interactive Sales Analytics Dashboard was created in Microsoft Power BI to visualize key sales and profit metrics.

The dashboard includes:

- KPI cards
- Monthly sales trend
- Sales by category
- Sales by region
- Top 10 products by sales
- Profit by category
- Category and Region slicers for interactive filtering

## Key Insights

- Electronics generated the highest total profit: ₹42,820.94.
- West was the highest-profit region: ₹17,337.75.
- Stationery had the highest profit margin: 28.83%.
- Monthly sales were analyzed to understand sales trends over time.
- The Top 10 products by sales were identified to understand product performance.

## Conclusion

The Sales Analytics project helped analyze sales and profitability using Excel and MySQL and present the findings through an interactive Power BI dashboard. The analysis provides a clear view of business performance across products, categories, regions, and months.
